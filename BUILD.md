# BUILD.md — Reproducible Build & Deployment Guide

This document details the environment configuration, build dependencies, and deployment procedure required to reproduce the `comfyui-generation-worker-v6` serverless runtime deployed on Modal.com for BrandVerita Studio (`app.brandverita.io`).

Providing this reproducible build guide satisfies the Corresponding Source build instructions required under GNU GPL-3.0 / AGPL-3.0 copyleft obligations.

---

## 1. System Requirements & Prerequisites

To build and run this worker locally or in a cloud environment, you need:

* **Operating System:** Linux (Debian 12 / Ubuntu 22.04 LTS recommended) or macOS
* **Python:** Version 3.10 or higher
* **Container Runtime / Cloud Platform:** [Modal CLI](https://modal.com/) (`pip install modal`)
* **GPU Hardware:** NVIDIA GPU with at least 16GB VRAM (e.g., NVIDIA A10G or L4) for local or custom container testing
* **CUDA Driver:** CUDA 12.1+ compatible drivers

4. Modal Worker Application Definition (modal_app.py)

Create or review the modal_app.py file at the root of the repository. This file defines the container image, PyTorch dependencies, system libraries, and worker runtime:

import os
import json
import modal

# Define the Modal App name
app = modal.App("comfyui-generation-worker-v6")

# Build Debian Slim base container with CUDA, PyTorch, and ComfyUI
comfyui_image = (
    modal.Image.debian_slim(python_version="3.10")
    .apt_install(
        "git",
        "ffmpeg",
        "libgl1-mesa-glx",
        "libglib2.0-0",
        "wget"
    )
    .pip_install(
        "torch==2.3.1",
        "torchvision==0.18.1",
        "torchaudio==2.3.1",
        extra_index_url="[https://download.pytorch.org/whl/cu121](https://download.pytorch.org/whl/cu121)"
    )
    # Clone and pin exact repo revision inside the container
    .run_commands(
        "git clone [https://github.com/brandverita/ComfyUI.git](https://github.com/brandverita/ComfyUI.git) /root/ComfyUI",
        "cd /root/ComfyUI && git checkout 344b43989e8c56b5bb4a66cf028c834192ab59dd",
        "pip install -r /root/ComfyUI/requirements.txt"
    )
)

@app.function(
    image=comfyui_image,
    gpu="A10G",
    timeout=600,
    container_idle_timeout=300,
    secrets=[modal.Secret.from_name("huggingface-secret")]

5. Execution & Deployment Commands
Local Verification / Staging Test

To execute the worker in an ephemeral test container on Modal:

modal run modal_app.py

Production Deployment

To deploy the worker as an active production endpoint (comfyui-generation-worker-v6):
modal deploy modal_app.py

6. Input Payload Standard (API JSON Format)

The deployed worker requires workflow instructions formatted using ComfyUI API Format JSON.

To generate a compatible payload:

    Open the ComfyUI web UI locally or in staging.

    Enable Dev Mode Options in settings (Gear Icon -> Enable Dev Mode Options).

    Construct or load the Outpaint / Smart Resize workflow.

    Export the workflow using the Save (API Format) button.

    Post the resulting JSON payload to the worker endpoint via POST request.
